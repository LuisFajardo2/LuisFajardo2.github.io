Cute Cat Calculator

Política de privacidad.

Última actualización: 16 de septiembre de 2026

Pandy Brandy ofrece Cute Cat Calculator y es responsable de esta política. Hemos diseñado la aplicación para funcionar con la menor cantidad posible de datos.

Cálculos y cuentas

Los números introducidos y los resultados se procesan localmente en tu dispositivo. La aplicación no crea cuentas, no envía tus cálculos a Pandy Brandy y no mantiene un historial permanente de operaciones.

Información guardada en el dispositivo

La aplicación guarda localmente el estilo elegido, el volumen de los sonidos, el saldo y los tiempos de recarga de galletitas, las actividades y accesorios del compañero felino, el grupo de edad y un identificador aleatorio de la última recompensa para evitar duplicados. Android también puede conservar temporalmente el cálculo visible para restaurar la pantalla. Puedes eliminar esta información borrando los datos de la aplicación o desinstalándola.

Portapapeles

La aplicación escribe un resultado en el portapapeles del sistema únicamente cuando eliges copiarlo. No lee el contenido del portapapeles.

Publicidad y proveedores externos

La aplicación ofrece anuncios recompensados opcionales de Google AdMob para obtener galletitas. No necesitas ver un anuncio para utilizar la calculadora. Google Mobile Ads puede recopilar y compartir la dirección IP —que puede utilizarse para estimar una ubicación general—, interacciones con la aplicación y los anuncios, información de diagnóstico e identificadores del dispositivo o de la cuenta para publicidad, medición, analítica y prevención del fraude. Estos datos se cifran durante la transmisión. La aplicación excluye el permiso del identificador publicitario de Android, pero Google puede tratar otros identificadores técnicos. No enviamos a Google los cálculos que introduces.

Google User Messaging Platform (UMP) muestra y conserva las opciones de privacidad aplicables. Cuando corresponde, puedes volver a abrirlas desde Ajustes, Privacidad publicitaria. La aplicación solicita anuncios no personalizados y solo inicia el SDK publicitario después de comprobar el estado de consentimiento. Consulta Cómo utiliza Google los datos de sitios o aplicaciones de sus partners y la Política de Privacidad de Google.

Edad, niños y familias

Antes de solicitar publicidad se muestra una pantalla neutral de edad. La fecha introducida se usa temporalmente para determinar el grupo de edad: no se guarda ni se envía. Solo se conserva localmente el grupo resultante. Para menores de 18 años y personas cuya edad se desconoce, la solicitud publicitaria se marca para tratamiento infantil, se limita la clasificación del contenido a G y se solicitan anuncios no personalizados. La aplicación no solicita nombre, correo, ubicación precisa, contactos, cámara ni micrófono.

Este sitio web

Este sitio no usa formularios, cookies de análisis ni rastreadores propios. Está alojado en GitHub Pages; GitHub puede registrar direcciones IP de visitantes por motivos de seguridad, conforme a su propia política de privacidad.

Cambios a esta política

Publicaremos aquí cualquier cambio e indicaremos la nueva fecha de actualización.
